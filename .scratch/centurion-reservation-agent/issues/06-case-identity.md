## Question

How should one selected email map to an existing reservation case, multiple guests, several rooms and possibly several distinct stays, while the staff member still gets one action for the work in that email?

The owner already chose one click for the complete reviewed work; do not ask whether that is wanted. Define how prior messages, forwarded duplicates, self-mail and explicit confirmation numbers are linked, and when an ambiguous match must be surfaced. Avoid assuming one email always equals one HMS reservation or that several rooms are automatically one guest.

Use representative known examples and recommend a concrete case/step identity model before asking only genuinely unresolved product questions.
