# Reservation opportunity analysis

## Language

**Potential Nava help**: At least one meaningful part of a historical request Nava could help with under a specified set of hypothetical working capabilities. Staff approval and other work done by staff do not disqualify it.
_Avoid_: Actual Nava usage, adoption

**Group request**: A request for more than 10 rooms for the same group. Exactly 10 rooms is below this threshold.

**Reservation email**: An inbound email about reservation work that needs action; multiple emails about one enquiry are counted separately. OTA work is excluded from this analysis.
