# Filing reply drafts

Receipt: “Thank you for sending [document]. We will check it against [verified stay, if known].”

Missing or unreadable: “Could you resend [file] and confirm [missing booking detail, if needed]?”

Verified duplicate: “This document is already on reservation [reference]. No additional copy was added.”

For a separate invoice, payment or refund question, acknowledge only staff work that was actually recorded and report only established outcomes.
