# Filing reply drafts

Proposed wording; no audited staff-verbatim template. Draft only. Fill placeholders from current evidence; never include raw card/bank credentials.

## Receipt only

“Thank you for sending [document type or filename]. We will check it against [verified booking details, if known].” Receipt does not confirm filing or payment.

## Missing / ambiguous

“Your message refers to [voucher/proof of payment], but we could not access it. Could you please resend the file and confirm [missing booking reference or guest/stay detail]?” Only after actual source check; ask only missing evidence.

Unpaid pro-forma labelled POP: “The attached document appears to be a pro-forma invoice. Could you please send the payment confirmation for [verified reservation]?”

## After verified fresh readback

“We have attached [document type/filename] to reservation [actual reference] for [guest], [dates].” Separate actual verified items. No “paid” claim from filing success.

## Duplicate / uncertain / separate inquiry

Verified duplicate: “This document is already on reservation [reference], so no additional copy was added.”

Uncertain: “We have received [document] and are checking whether it is on the reservation.” No repeat upload while unverified.

Payment/invoice/refund status unavailable: “Our team will check [specific question] and follow up.” Only when staff-review task recorded. No promise of issued invoice/refund/cleared funds absent evidence.
