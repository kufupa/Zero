# Create reply drafts

In 50 response-conditioned journeys, staff replies contained “reservation is provisional” in 34/50, “Please see attached” in 5/50, and “Please find attached” in 6/50. These are overlapping phrase counts, not proof of booking state. Use provisional language only when the actual status and condition are known, and mention an attachment only when available.

After a confirmed Save and readback: “Your reservation for [guest] is confirmed: [arrival] to [departure]. Booking reference: [actual reference].” Include rate, board, billing or payment only when verified. For a genuinely missing guest detail, ask for that detail alone.
