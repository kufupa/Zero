# Quote reply drafts

Use the requester's known first name. Do not name unrelated organizations; the client's own verified organization may be confirmed to its direct booker.

Draft one cover email and one signable PDF and editable Excel per requested party. Use `quote_artifacts` if registered; name only returned files and surface missing ones to staff. Inline a simple verified price if helpful. State room, dates, occupancy, meals, price basis and currency as supported. A quote does not reserve rooms.

For incomplete criteria, ask only for the missing detail. For native-confirmed unavailability, use a short decline scoped to the unavailable rooms and dates. Offer alternatives only from verified results chosen by staff.
