# Quote reply wording

## Attachment / Signature

Draft “Please see attached quotation” only with actual artifacts. Ask for signed return only when actual quote artifact exists and current instruction supports it. “No rooms currently held” only when absence of earlier holds is supported; otherwise say quote itself does not hold rooms. No universal signed-quote prerequisite inferred. Never promise inventory held.

## General draft

“For [arrival] to [departure], we can offer [quantity, room type, occupancy] with [meal plan] at [verified price, currency, per-room/per-night or native stated basis]. [Verified availability/restrictions]. This quotation does not reserve or hold rooms. Please let us know if you would like to proceed.”

List alternatives by room/rate/board; label public rate alternative when contracted option unavailable. Total only official/native-supported, otherwise clearly identified estimate. No invented fees, child bands or quote expiry.

## Missing criteria

“Could you please confirm [dates/room count/occupancy/child ages/meal preference] so we can check the appropriate options?” Ask actual gaps only; do not request already-supplied facts.

## Native unavailability

“The requested [specific room/rate] is not available for [dates]. [Verified alternative, if any].” “Fully booked” only native evidence establishes whole requested inventory condition; failed search/unknown row insufficient.

## Existing booking / invoice

Current booking-status ask → status/read or staff review, not fresh quote. Don't promise pro-forma, PDF or Excel absent actual supported artifact/work item.
