# Quote reply wording

## Attachment / Signature

R4: cover + signable PDF + editable Excel (owner 2026-11-17; attachment wording 44/338 outbounds, 0/338 named file format). “Please see the attached quotation and editable workbook” only when both returned. Name only actual files; missing file stays visible to staff. Ask for signed return when appropriate. Quote does not hold rooms; don't infer no earlier hold.

## General draft

R1: greet “Hi [verified first name],” when known; do not name the company in the reply. Never invent a name.

R4: simple single-room/night price may go inline in cover (23/338 outbounds included inline prices). “For [arrival] to [departure], we can offer [quantity, room type, occupancy] with [meal plan] at [verified price, currency, unit]. This quotation does not reserve or hold rooms. Please let us know if you would like to proceed.”

List alternatives by room/rate/board; label public rate alternative when contracted option unavailable. Total only official/native-supported, otherwise clearly identified estimate. No invented fees, child bands or quote expiry.

## Missing criteria

“Could you please confirm [dates/room count/occupancy/child ages] so we can check the appropriate options?” Ask actual gaps only. R5: if board remains unclear, “Would you prefer dinner, bed and breakfast, or bed and breakfast only?” (22/33 priced replies BB; 11/11 government-rate replies DBB; native plan decides.)

## Native unavailability

R2: 1–3 sentences (6/12 declines offered alternatives; 2/12 one-liners). “We are unable to offer [requested room/stay] for [dates]. We do have [verified nights/rooms] and would be happy to quote for those.” Omit second sentence if no verified partial availability. Sister hotel only if staff adds (1/12). “Fully booked” only when native evidence establishes it; failed search/unknown row insufficient.

## Existing booking / invoice

Current booking-status ask → status/read or staff review, not fresh quote. Don't promise invoice or file absent supported artifact/work item.
