Reservations and/or Group Reservationist, Front Office, Guest Relations,  
and Rooms Division Manager 
 
 
Policy: 
 
The number format for all local numbers entered on INFOR HMS should be entered using just one “0”  
Then the rest of the home/business or mobile number can be entered. 
 
The format for international numbers entered on INFOR HMS should be entered using “00"  
Then the rest of the home/business or mobile number can be entered. 
 
There should no spaces or lines in between. 
 
 
Purpose: To ensure all numbers are entered correctly into the system.
