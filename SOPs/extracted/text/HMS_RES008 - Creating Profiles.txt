HMS_RES008 Guest Profiles

Responsibilities:   
 
Reservations, Front Office and Reservations Manager 
 
Policy: 
 
• Guest Profiles allows INFOR HMS users access to profiles (Individual) held in the central 
database.   
• Organization Profiles allows INFOR HMS users access to profiles (Organization) held in the 
central database.   
• Agency Profiles allows INFOR HMS users access to profiles (Agent) held in the central 
database.   
 
Before creating a new profile in your INFOR HMS, always check the profile database to ensure the 
profile does not already exist. 
 
The guest profile is also extremely important for ensuring that the correct individual profile is used 
when making a reservation for a LL (Legacy Lifestyle) member. Downloading the correct profile will 
ensure that all the guest’s reservations will be attached to the correct profile and that the Lifestyle 
Rands accumulate correctly.   
 
 
 
Definitions:  
 
INFOR HMS–Hotel Management System 
  
 
Procedure:  
1. Creating a New Profile 
 
1.1 When creating, a new profile, search your guest on guest profile to see if the profile does not already 
exist.    
 
1.2 Should the profile not exist, proceed to create the guest profile.
