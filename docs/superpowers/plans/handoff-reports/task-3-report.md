## RCA notes for failures encountered

- **Vitest `Cannot find module '@zero/server/*'` (first run):** root cause was `new URL('./src/...', import.meta.url).pathname` returning a POSIX-style path without a drive letter on Windows, which vite's alias resolver rejected. Fix: use `fileURLToPath(new URL(...))` which returns a proper Windows path. Re-ran: 5/5 pass.
- **`tsc` TS2835 `Relative import paths need explicit file extensions`:** root cause was `moduleResolution: NodeNext` requiring `.js` extensions on relative imports even for `.ts` source. Fix: changed `import { getSocialProviders } from './auth-providers'` to `'./auth-providers.js'`. Re-ran build: clean.
- **`tsc` TS2742 `inferred type of 'createAuth' cannot be named without a reference to .../better-auth.jwa4Tx7v.js`:** root cause was better-auth's exported types not being portable when inferred; `tsc --declaration` needs an explicit type annotation. Fix: annotated `createAuth` return as `ReturnType<typeof betterAuth>`. Re-ran: clean.
- **`dist/` nested under `dist/src/`:** root cause was `rootDir: "."` with `include: ["src/**/*.ts"]` — tsc preserved the `src/` directory prefix in output. Fix: `rootDir: "src"`. Re-ran: flat `dist/main.js`.
- **EC2 `pnpm install --frozen-lockfile` (full monorepo) exceeded SSM 900s timeout:** root cause was native dependency builds (better-sqlite3, sharp, esbuild, workerd) on a small EC2 instance taking >15 min under the SSM agent. Fix: scoped install with `--filter '@zero/server...'` which only builds server-pilot's dependency subtree. Success.
- **EC2 `pkill -f 'dist/main.js'` returned "Operation not permitted":** root cause was the backgrounded `node dist/main.js` being a child of the SSM-run `bash -lc` shell owned by ubuntu; `pkill` matched but couldn't signal because the shell had already become the process group leader and the node child was being reaped. The node process was terminated when the SSM shell received SIGTERM (exit 143). Verified `NO_NODE_RUNNING` afterwards with `ps -u ubuntu`.
