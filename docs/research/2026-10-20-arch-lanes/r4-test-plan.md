## 2. Testing/eval mistakes to avoid

1. **Circular or weak truth.** The 42-row party run reused 22 binds already accepted from the system under test; a 20/22 score is not independent truth. Domain-majority truth is not per-email truth, and a staff quote may choose the first option while reservation party binding has a different target. Keep source/provenance and corpus window/outbound coverage in every report (docs/context/MISTAKES.md:13,17,23; AGENTS.md:74; docs/context/ACTIVE.md:9–11).
2. **Small samples and tuning noise.** No rate from <100 independent held-out truth IDs. Run baseline twice on fresh rows before tuning; one baseline or a 30-row tuning gain can be noise and can disappear on fresh rows (docs/context/MISTAKES.md:27; AGENTS.md:69,74).
3. **Wrong input.** Body-only replay missed attachment-bearing mail; 74% of gold inbound had attachments. Triage v4 also had no vision. State body, attachment text, selection context, and vision parity in each brief; matching row IDs alone is not parity (docs/context/MISTAKES.md:26; AGENTS.md:68; docs/context/ledger/2026-10-19-afternoon-retro.md:37–42,55–62).
4. **Wrong baseline/metric.** Deterministic sender/history/exact-match baseline was not scored before an LLM party loop. “Same move as staff,” readiness, line-total agreement, a refusal, or completed browser run are not rate-plan/nightly-price accuracy. Score the cheapest deterministic option first and name what the metric excludes (docs/context/MISTAKES.md:13; AGENTS.md:73; docs/context/FACTS.md:83–89,143–149).
5. **Batch and plumbing failures masquerading as behavior.** HMS LOCK_BUSY stopped 16/194 rows without retry; serialized live quote mail took too long; test plumbing consumed 52.4m plus 9m rework and 7m stuck time. Add bounded retry/backoff and persist progress; one live read at a time, not an unbounded batch (docs/context/MISTAKES.md:14,49; docs/context/ledger/2026-10-19-afternoon-retro.md:37–42).
6. **Unit-only or wrong-DOM proof.** Unit tests cannot validate live HMS DOM, ARIA locator correctness, login/profile state, or a browser bundle. One read-only DOM probe caught an unverified path; cold-profile login failed despite 12/12 unit tests. Use current DOM evidence and real production-shaped fixtures (docs/context/MISTAKES.md:31–33,56–58,65–71; docs/context/ledger/2026-10-19-afternoon-retro.md:37–42; AGENTS.md:72).
7. **Stale/divergent tests and incomplete UI briefs.** Shared helpers, stale snapshots, tests against old code, and omitted test files asserting removed UI caused type/test failures and delays. Before UI change list every asserting test; update code and fixtures together. A source-grep test is not a behavioral test (docs/context/MISTAKES.md:9,56–62; docs/context/ledger/2026-10-19-evening-retro.md:24–26,44–50; docs/context/ledger/2026-10-08-overnight.md:37,43,47).
8. **Procedure plumbing and cold-start gaps.** A tRPC client Proxy looked unlike a normal function; new procedures must be classified; viewer onboarding/cold profile can break the real route. Cover procedure registration and cold browser state, not only injected happy-path functions (docs/context/MISTAKES.md:56–62; docs/context/ledger/2026-10-08-overnight.md:30,37,43,47,69–71).
9. **E2E is not done when one subsystem passes.** A targeted run had 7/8 analysis but an unsynced row; a quote harness failed after HMS success. A live HMS operation alone does not prove pane-to-result flow, and a 12/12 unit pass did not prove live login. Track one end-to-end acceptance record across input, UI, HMS result, and artifact (docs/context/ledger/2026-10-08-overnight.md:83,91,104,113; docs/context/ledger/2026-10-19-afternoon-retro.md:37–42).
10. **Red-first/sequential/stale review gates.** Chain lane, remote typecheck, and diff review in the lane background; run gates in parallel, not red-first; refresh review base; no self-review subagents. Count P1 only when reachable from a current staff/prod path; a fresh adjacent P1 at round 3 means split/strip/redesign. List every UI test asserting removed UI; do not edit shared gate scripts; coordinator reads the final product diff. Monitor by PID and never relay an owner approval between sessions. Party binding also regressed after unit+Greptile-only review: replay the same commit before merge and inspect blocked rows (AGENTS.md:65–76; docs/context/MISTAKES.md:7–10; docs/context/ledger/2026-10-19-evening-retro.md:24–26,44–57).
11. **Post-deploy proof omitted.** Green unit tests do not prove nginx bundle load, Outlook pane, webmail, or real prepared-quote visibility. Verify the deployed bundle and both inbox surfaces. Production feature done is golden-set performance, not merge (docs/context/MISTAKES.md:65–71; PRODUCT.md:57–73,98).
12. **Memory and label provenance.** Reuse settled research; report whether labels are staff-authored, staff-corrected, model-confirmed, or silver. Eight owner-gold rows do not turn a 431-row silver score into gold truth (docs/context/MISTAKES.md:43,45; docs/research/2026-10-19-leak-free-triage-eval.md:15–20,22–37).
