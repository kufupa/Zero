## 3. Singular labels, index zero, and multi-stay edges

### One label can route the whole email

- **Source**: deterministic `direct` / channel / system source kind gates admission and prefetch. `apps/server-pilot/src/ai/mail-source.ts:3-7,103-117,172-211`.
- **Triage**: one `primaryFolder` label routes category/apply, not the pane workflow by itself. `apps/server-pilot/src/ai/workflows/mail-triage.ts:103-206`; `apps/server-pilot/src/ai/worker.ts:4750-4764`.
- **Extraction**: one top-level `kind` and one `action` represent the whole extraction. `apps/server-pilot/src/ai/extraction/schema.ts:32-45,274-301`.
- **Workflow classifier**: one coarse `workflow`; medium/high classifier result overrides the `kind`→workflow mapping. `apps/server-pilot/src/ai/workflow-classifier/index.ts:6-31,49-74`; `apps/server-pilot/src/ai/work-items.ts:220-249`.
- **Pane**: one `readAs` choice wins for the selected work item/email. `apps/mail/lib/quote-workflow/workflow-vocabulary.ts:74-122`.

These are separate labels with separate jobs. Do not read the triage folder as the booking/quote action: extraction kind/action, coarse workflow, and final `readAs` are later decisions.

### Index-zero and refusal/collapse points

- Work-item booked/requested overlay uses `stays[0]`; confirmation overlay uses `confirmationNumbers[0]`. Pane-ready summary again selects only first stored confirmation. `apps/server-pilot/src/ai/work-items.ts:353-380,1274-1320`.
- Batch HMS prefetch uses first confirmation candidate; no-confirmation guest lookup requires a unique arrival. `apps/server-pilot/src/ai/hms-jobs.ts:369-387,487-513`.
- Booking-kind quote preparation refuses `stays.length !== 1` or any confirmation; quote-kind plan still maps all stays. `apps/server-pilot/src/ai/quote-ready.ts:39-52,209-255`.
- Multiple date sets can survive as groups, but extractor has no guest key per stay and one work item is ensured per message/kind. Same-date guests therefore cannot be reliably split after extraction; multi-ask action cannot be reconstructed by pane edits alone. `apps/server-pilot/src/ai/extraction/extract.ts:42-65`; `apps/server-pilot/src/ai/extraction/schema.ts:57-99`; `apps/server-pilot/src/ai/work-items.ts:275-350,525-577,649-691`.
- Quote analysis keeps one party/contact and overall sales strategy even when prepared stay groups are multiple. Party prefetch also queues one candidate per extraction. `apps/server-pilot/src/ai/quote-ready.ts:209-255`; `apps/server-pilot/src/ai/hms-jobs.ts:442-485,1831-1955`.

## 5. Required prompt/schema work vs pane-only
