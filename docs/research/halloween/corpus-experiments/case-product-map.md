# Journey-to-product map

Each row asks what the reviewed observation changes for Nava and which HMS capability would matter. These are product implications, not proof of missing code or current deployed behavior. The owner says the HMS tools are being rewritten from scratch. References to existing source in the [historical inventory](tool-inventory.md) are not proof that the rewritten tools provide those capabilities. Labels and source evidence are in [booking journeys](booking-journeys.md) and [quote journeys](quote-journeys.md).

| Case | What Nava should recognize or prepare | Relevant HMS capability and boundary |
|---|---|---|
| B01 | Recognize an existing-stay extension. Keep two identifiers as a candidate relationship rather than assuming they refer to the same record. | Find each referenced reservation and read stay details; an extension write would be separate and staff-approved. The reason for the ID change is unknown. |
| B02 | Preserve requested dinner and the named guest. Do not require a staff “booked” reply to find possible related evidence. | Match reservation candidates by supported identity and dates; read the rate and meal facts without assuming the request's dinner allowance was included. The request-to-PDF match is a candidate. |
| B03 | Separate booking request, staff's statement, original confirmation and later internal forward. Do not create another booking because a confirmation arrived. | Find the existing confirmation. A separate create flow requires an explicit staff-approved decision; the original write and delivery were not directly observed. |
| B04 | Keep simultaneous requests from the same agency distinct by guest and dates. Do not treat sender alone as a binding. | Search agency candidates and read the property-specific rate and availability; find the exact confirmation when supplied. Do not infer an eligible government rate from the sender. |
| B05 | Treat the voucher-related message as existing-stay context, not automatic create or proof of payment. Do not assume quoted text preserves original authorship. | Find the confirmation and read relevant reservation facts. A voucher or quoted identifier alone does not establish payment or authorization to write. |
| B06 | Recognize a request, confirmation reference and later voucher-related exchange even across threads and a longer interval. | Find and read the referenced reservation. Do not equate a voucher-related exchange with a paid balance. |
| B07 | Keep travel-agent requests in scope even when a later HMS source label differs from email. | Search and explicitly select the relevant agency, then read eligible rates; use the actual property and stay context, not the later source-of-business value as an email filter. |
| B08 | Preserve one request referring to multiple stays and transfers. Mark missing guest-list details unknown. | Find each supported confirmation separately. Guest-list extraction and transfer handling need their own evidence; do not claim the reservation reader covers them. |
| B09 | Distinguish requested, discussed and documented dates and occupancy. Recognize a French amendment and an accompanying transfer request. | Find and read the current stay before showing a proposed comparison. A guarded amend path exists in source for certain stay fields; transfer-write support is not established. |
| B10 | Do not bind an invoice request to a stay using sender alone when its attachment is unavailable. | If a stay is reliably identified, document or folio reads may be relevant; their current Centurion availability was not established. Otherwise leave the association unknown. |
| QJ-01 | Recognize a quote request with dinner and no held room. Keep a request for a quote separate from consent to book. | Read availability and eligible rates, preserving dinner separately when not priced. A claimed attachment is not verified file content. |
| QJ-02 | Recognize room-only negotiation and a staff-communicated price, not a confirmed booking. | Read applicable room-only rates; handle any authorized manual rate under product rules. Management involvement is evidence of staff behavior, not proof of a particular HMS rate. |
| QJ-03 | Quote several single rooms per room and night. Treat withdrawal of a quotation as a quote outcome, not a reservation cancellation. | Read room-type availability and B&B pricing for the requested room count. No selected confirmation was addressed to the requester, but a different-recipient booking cannot be ruled out. |
