# Supported-task consistency review

Mark potential Nava help true only if the current email contains at least one supported task: an individual quote, reservation creation, reservation amendment, cancellation, supplied payment-proof or voucher filing, or reservation invoice. Tag that task explicitly.

Checking guests in, checking whether a payment has cleared, asking the guest to pay, arranging a shuttle, and general `other` work do not by themselves qualify. If a separate supported task is present, it can still qualify. Merely mentioning an earlier invoice or an earlier proof submission is not a new invoice request or a newly supplied document.
