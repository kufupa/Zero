## Labeling unit and safe local method

- Use **request × stay × action** units, retaining parent thread/message IDs privately: one mail can refer to four separate existing confirmations, and multi-stay allocation may remain unknown. [docs/research/halloween/corpus-experiments/month-stay-cases.md:11-13,21-27]
- Per unit, preserve: exact authored ask/span; stay/reference candidates; field + requested value (dates/nights, occupancy/children, room/rate/board, add-on/transfer, party/guest, note, payment/refund); current HMS value only when read; ambiguity/confidence. [docs/research/halloween/corpus-experiments/booking-journeys.md:31-34; apps/server-pilot/src/ai/reservationist-extraction.ts:13-15]
- Keep outcomes separate: **asked** → staff accepted / refused-with-reason / clarified / offered alternative / pending-or-no saved reply → HMS mutation and fresh readback (field diff, fee/charge). Staff wording or a changed PDF alone is not HMS-save proof. [docs/research/2026-10-20-arch-lanes/l2-amend-payment.md:22-24,65-72,114-140; docs/research/halloween/corpus-experiments/booking-journeys.md:26,31-34]
- Build context from the full *relevant* thread: current authored request first; earlier quoted/forwarded messages, staff replies and linked attachments as dated context, never fresh asks by themselves. Filter repeated banners, signatures and legal/footer boilerplate from intent text; extraction rules already treat quoted history and routine notices separately. [apps/server-pilot/src/ai/reservationist-extraction.ts:13-15,81; docs/research/halloween/corpus-experiments/booking-journeys.md:32-34]
- Retain only attachments tied to the current/earlier relevant message and authorized thread scope, with source hash/page provenance. Current saved mailbox snapshot lacks raw MIME and attachment descriptors; its separate PDF subset is outbound, so absent PDF rows cannot mean “no inbound attachment.” [apps/server-pilot/src/ai/reservationist-attachment-input.ts:113-150,164-209; docs/research/halloween/corpus-experiments/month-source-inventory.md:58-61]
- For relevant PDFs, use Poppler layout text with page boundaries; inspect image-only material separately. Prior checks found Poppler preserved a confirmation label missed by another extractor, while image-only headers/banners were absent from native text and two-column clause order was interleaved. [docs/research/halloween/2026-10-29-centurion-three-day-reread.md:51-63]
- Next pass: declare date/window and inclusion rule; retain all eligible requests including no-reply/declined/withdrawn; stratify candidates + complement; independently check labels and source spans; publish only anonymized counts, denominators, method and uncertainty. Do not treat the 5 purposive cases or 223 heuristic events as a gold set. [docs/research/halloween/corpus-experiments/month-sample-protocol.md:5-14,18-23; docs/research/2026-10-20-arch-lanes/l2-amend-payment.md:20-24]
