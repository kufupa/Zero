# Pomerado native MCP: source review

Date: 2026-10-27. Scope: read-only review of the public source checkout at `7349a1c2` for owner ask 309. No hotel access, model call, MCP launch, or runtime test. The reviewer checked source and docs, not the private trial logs. Source behavior is not a live proof.

| Question | Source finding | Planning consequence |
|---|---|---|
| Mint inputs | Native `mint` requires `name`, `url`, `intent`, `effect`; `input` and `authenticationOrigins` are optional. A name must be fresh and match the tool’s naming rules. [Server schema](https://github.com/Pomerado/pomerado/blob/7349a1c2/typescript/src/standalone/mcp-server.ts#L55-L69) · [validation](https://github.com/Pomerado/pomerado/blob/7349a1c2/typescript/src/standalone/artifact-files.ts#L35-L53) | Give the private tenant URL, `read` effect, short intent and one private example. Do not delete a prior artifact to reuse its name. |
| Intent and inputs | Intent becomes the integration tool description and is stored in its deployment configuration. Example input is separate. [Packaging](https://github.com/Pomerado/pomerado/blob/7349a1c2/typescript/src/standalone/mcp-package.ts#L51-L53) · [README](https://github.com/Pomerado/pomerado/blob/7349a1c2/README.md) | Keep credentials and guest values out of intent; keep example data, artifacts and logs in the approved private workspace. |
| Native job flow | Mint returns a job. `get_job` waits and reports status; `provide_input` supplies answers by job and request IDs. All requested questions need answers. Input requests expire after ten minutes. [Server](https://github.com/Pomerado/pomerado/blob/7349a1c2/typescript/src/standalone/mcp-server.ts#L106-L155) · [input validation](https://github.com/Pomerado/pomerado/blob/7349a1c2/typescript/src/runtime/input-request.ts#L500-L534) | Use the registered tools, keep the session and respond promptly. The exact credential answer wire shape was not verified. |
| Terminal result | `completed` may contain `build: published` or `build: incomplete`. Failed and cancelled jobs are not publication. Finished in-memory jobs expire after fifteen minutes. [Server](https://github.com/Pomerado/pomerado/blob/7349a1c2/typescript/src/standalone/mcp-server.ts#L196-L218) · [jobs](https://github.com/Pomerado/pomerado/blob/7349a1c2/typescript/src/standalone/mcp-jobs.ts#L272-L286) | Capture the actual build result promptly; do not treat `completed` as a pass. |
| Server lifetime | Mint and read-integration jobs are in memory. A server restart loses them. [Server](https://github.com/Pomerado/pomerado/blob/7349a1c2/typescript/src/standalone/mcp-server.ts#L164-L184) · [job storage](https://github.com/Pomerado/pomerado/blob/7349a1c2/typescript/src/standalone/mcp-server.ts#L329-L332) | Keep the original native server alive during each active job. Do not restart a progressing job. |
| Login and private output | Credential requests pass answers through the MCP client and model; vendor docs say the answers are not saved as credentials. Integration runs may ask for login again. Run output is not redacted. [Setup](https://github.com/Pomerado/pomerado/blob/7349a1c2/docs/agent-setup.md) · [how it works](https://github.com/Pomerado/pomerado/blob/7349a1c2/docs/how-it-works.md#L230-L232) | Protect controller logs and outputs. Respond to already-authorized credential requests without re-asking the owner. |
| Runtime URL | Vendor docs say a generated run starts at the site root. The earlier HRCEN root returned 404; the tenant URL worked for independent login. [Vendor runtime](https://github.com/Pomerado/pomerado/blob/7349a1c2/docs/how-it-works.md#L230-L232) · [trial evidence](2026-10-27-pomerado-readstay-test.md) | Tell Pomerado to use the tenant application URL on every lookup and inspect generated navigation before replay. This does not prove the new build fails. |
| Read authority | Guardian and mint authority are not an independently enforced runtime write barrier. Vendor says generated code is not sandboxed and runs are not re-reviewed by Guardian. [How it works](https://github.com/Pomerado/pomerado/blob/7349a1c2/docs/how-it-works.md) · [README](https://github.com/Pomerado/pomerado/blob/7349a1c2/README.md) | Keep the approved `read` authority, Guardian, source review and privacy boundary. Do not reinstate the assistant-added sandbox-proof gate removed in ask 304. |

Vendor source contains a twenty-minute active-mint default, but the reviewer did not trace the complete effective configuration path. Treat it as a possible vendor-side deadline, not a verified deadline for this build and not permission for a coordinator to cancel early. The credential answer wire shape, actual provider routing per call, updated runtime behavior and whether site-root handling works for HRCEN remain unverified.
